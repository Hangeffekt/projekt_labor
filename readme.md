Projekt:
Ez a projekt a Projektlabor tantárgy keretében készült.
A cél egy PHP alapú, SQL adatbázist használó webshop rendszer megvalósítása, amely lehetővé teszi a felhasználók számára a termékek böngészését, kosárba helyezését és a rendelések leadását.

Az alkalmazás kliens–szerver architektúrára épül, ahol a backend működését PHP, az adatok tárolását pedig SQL adatbázis biztosítja.

Technológia	Feladat
PHP	Backend és szerveroldali logika
MySQL / MariaDB	Adatbázis-kezelés
HTML5	Oldalak szerkezete
CSS3	Megjelenítés és formázás
JavaScript	Kliensoldali interakciók
Apache	Webszerver
Git	Verziókezelés
